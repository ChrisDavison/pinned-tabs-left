# Pinned Tabs Left

Keeps pinned tabs at the left of every tab group, so new tabs open after them. It re-sorts each group when the layout changes, the active tab changes, or a tab is pinned or unpinned.

## Install

Install with [BRAT](https://github.com/TfTHacker/obsidian42-brat) using `ChrisDavison/pinned-tabs-left`, or copy `main.js` and `manifest.json` from the latest release into `<vault>/.obsidian/plugins/pinned-tabs-left/`.

To install a local checkout into a vault, run `./copy.sh <vault>`.

## Limitations

It relies on undocumented internals of Obsidian's workspace, so a future Obsidian release could break it.
